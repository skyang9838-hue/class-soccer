# 교실 축구 — 설계

2026-11-04 사용자와 질문으로 정함. "사용자가 정함" 표시가 없는 줄은 클로드가 넣은 기본값이라 바꿀 수 있다 (맨 아래 "아직 안 정한 것").

## 무엇
반 아이들이 교실에서 각자 노트북으로 접속해 같이 하는 귀여운 2D 축구 웹앱. 한 판씩 돌아가며 뛰고, 기록이 계속 쌓인다.

## 쓰는 상황 (사용자가 정함)
- **교실에서 다 같이.** 선생님이 판을 연다.
- 아이들 기기: **윈도우 노트북** (크롬·엣지), 키보드 조작. 화면은 약 1280×650 기준 (디노에서 잰 학생 노트북 크기).
- 처음 쓸 날: 정해지지 않음.

## 경기 규칙 (사용자가 정함)
- **인원 유동적**: 6대6이 아니어도 되고, 팀 인원이 안 맞아도 된다 (예: 5대6).
- **한 판 = 시간제, 기본 3분.**
- **마지막 1분은 한 골 = 2점.** 1분 남으면 화면에 크게 알린다 ("⚡ 이제부터 한 골 2점!") + 효과음.
- **골키퍼 없음.** 모두 필드 선수.
- **공은 벽에 튕긴다.** 아웃·스로인·코너킥 없이 멈추지 않고 진행.
- 골이 들어가면 잠깐 멈추고 가운데에서 다시 시작 (기본값: 먹힌 팀 공).

## 조작 (사용자가 정함: 패스·슛 따로)
- 방향키(또는 WASD)로 움직임.
- **패스 키**: 가까이 있는 우리 팀 쪽으로 약하게 찬다.
- **슛 키**: 보고 있는 방향으로 세게 찬다.
- 기본 키: 패스 `Z`/`J`, 슛 `X`/`K` (바꿀 수 있음).
- 공에 닿으면 몸으로 밀린다 (드리블).

## 화면 (사용자가 정함)
- **모두 경기장 전체를 본다.** 카메라 이동 없음. 내 선수는 머리 위 ▼ 표시 + 이름표.
- 선수 모습: **동글동글 사람(SD, 머리 큰 작은 사람)**. 팀은 유니폼 색(빨강·파랑), 아이는 이름표로 구분.
- 위쪽: 점수 · 남은 시간.
- **소리: 효과음 + 배경음악** (골·휘슬·1분 알림). 소리 끄기 버튼은 둔다 (기본값).

## 입장 (사용자가 정함: 방 코드 + 이름)
- 선생님 화면에 **4자리 방 코드**가 크게 뜬다. 아이는 주소에 들어가 코드와 이름을 입력. 로그인 없음.
- 같은 방에 같은 이름이 있으면 "다른 이름으로" 안내.
- 창을 닫았다 같은 코드·이름으로 다시 들어오면 원래 자리로 돌아간다 (경기 중이면 그 선수 그대로).

## 팀 짜기와 순서 (사용자가 정함)
- **경기 중 교체 없음. 한 판 끝날 때마다 새로 짠다.**
- 선생님이 직접 정하거나 **[랜덤]**. 랜덤은 **지난 판에 안 뛴 아이가 먼저** 들어간다.
- 이번 판에 안 들어간 아이는 "관전".
- 한 판에 뛰는 인원은 선생님이 정한다 (기본값: 들어온 아이가 12명 이하면 전원).

## 관전 (사용자가 정함)
- 안 뛰는 아이는 **자기 노트북으로** 같은 경기 화면을 본다 ("관전 중" 띠).

## 선생님 화면 (사용자가 정함)
- 방 만들기 → 방 코드.
- 대기실: 들어온 아이 목록, **아이 내보내기** (✕).
- 팀 짜기: 랜덤 / 이름 눌러 팀 바꾸기·빼기.
- 경기 중: **일시정지 · 강제 종료.**
- 결과 → [다음 판].
- 기록 보기.
- (경기 시간 바꾸기·기록 고치기 기능은 사용자가 고르지 않음 → 처음엔 안 넣음)

## 기록 (사용자가 정함: 계속 기록)
- 날이 바뀌어도 쌓인다: 아이별 뛴 판 · 이긴 판 · 골, 누적 득점 순위.
- 한 판 끝나면 결과 화면: 점수 + 그 판에 골 넣은 아이.
- 아이는 이름으로 구분한다 (로그인이 없으니 같은 이름 = 같은 아이). 기록은 선생님 방(반)에 묶인다 — 방 코드는 날마다 새로 나와도 같은 반 기록에 쌓이게 "반"을 따로 둔다 (기본값).
- 실명이 저장되므로 저장소·기록은 공개하지 않는 곳에 둔다.

## 화면 흐름
**선생님**: 방 만들기 → 대기실 → 팀 짜기 → 경기 → 결과 → (팀 짜기로) · 언제든 기록 보기
**아이**: 입장(코드·이름) → 기다리기(내 팀 색 표시) → 경기 또는 관전 → 결과 → 기다리기

## 만드는 방식 (사용자가 정함: 1번)
**방마다 작은 서버가 경기를 계산한다.**
- Cloudflare Workers + Durable Objects. 방(반) 하나 = Durable Object 하나.
- 서버가 공·선수 움직임과 골·시간·점수를 계산한다 (서버 권한형). 아이 노트북은 키 입력만 보내고 받은 상태를 그린다 → 모두 같은 경기를 본다.
- 연결은 WebSocket. 서버 계산 초당 30번, 화면은 그 사이를 부드럽게 이어 그린다.
- 기록은 Durable Object 저장소(SQLite)에.
- 무료 범위로 충분할 것으로 본다. 잠들었다 깨는 지연 없음.
- 화면: 정적 페이지(HTML·Canvas·JS). 같은 Worker가 내려준다.

고른 이유: 12명 이상이 실시간으로 움직일 때 "다 같은 화면"이 제일 중요하고, 계속 쌓이는 기록과도 맞는다. 고르지 않은 것: 선생님 노트북 서버(학교망이 막을 수 있고, 창 닫으면 끝, 기록이 한 컴에만) · 실시간 DB(공 위치가 아이마다 어긋남).

## 나누기 (구현할 때의 덩어리)
1. **경기 계산** — 선수·공 움직임, 벽 튕김, 패스·슛, 골, 시간, 마지막 1분 2점. 서버·화면과 떨어진 순수 코드라 따로 테스트한다.
2. **방 서버** — 입장·내보내기·재접속, 팀 짜기(안 뛴 아이 먼저), 판 진행, 기록 저장.
3. **아이 화면** — 입장, 기다리기, 경기·관전 그리기, 결과, 소리.
4. **선생님 화면** — 방 코드, 대기실, 팀 짜기, 일시정지·종료, 기록 보기.

## 점검
- 경기 계산: 골 판정 · 벽 튕김 · 마지막 1분 2점 · 시간 끝 판정 단위 테스트.
- 팀 짜기: 안 뛴 아이 먼저, 인원 안 맞을 때, 같은 이름 막기 테스트.
- 실제: 가짜 아이 12~20명(자동 접속 스크립트)으로 한 판 돌려 끊김·어긋남 확인. 학생 노트북 크기(1280×650)에서 화면 확인.

## 아직 안 정한 것 (만들기 전에 묻거나, 기본값으로 가고 해 보며 고친다)
- 경기장 크기·선수 속도·공 세기 (해 보며 맞춤)
- 키 배치 (기본: 방향키/WASD + Z·X 또는 J·K)
- 골 뒤 다시 시작할 때 누구 공인지
- 한 판에 뛰는 최대 인원
- "반"을 어떻게 만들고 고르는지 (예: 선생님이 반 이름을 한 번 만들어 둠)
- 배경음악·효과음 출처 (무료 음원)
- 앱 이름
- 저장소 공개 여부 — 코드에는 실명이 없으니 공개해도 되지만, 기록은 배포된 서버에만 둔다
